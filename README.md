# 🌌 Gravity Weaver

A fast-paced, 2D physics-based web game built using pure JavaScript and HTML5 Canvas. Players alter environmental gravity by weaving directional force vectors to guide a cosmic orb through hazardous dimensions into the goal portal.

## 🚀 Live Demo
[Play Gravity Weaver Live](https://your-username.github.io/gravity-weaver)

## ✨ Key Features
* **Custom Physics & Vector Mechanics:** Real-time trajectory calculation, velocity drag, and directional gravity manipulation.
* **10 Level Campaign:** Progressively scaling difficulty featuring static barriers, oscillating sweepers, high-speed vertical pistons, and narrow chokepoints.
* **Responsive Touch & Drag Controls:** Full mobile and desktop compatibility using native touch and pointer event listeners.
* **Visual Effects:** Dynamic particle explosion systems and visual force-vector indicators.
* **State Management:** Instant level retries allowing seamless level mastery without game-over resets.

## 🛠️ Tech Stack
* **Language:** JavaScript (ES6+)
* **Rendering:** HTML5 Canvas API
* **Styling:** CSS3 (Flexbox, CSS Animations)
